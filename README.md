# FlyBird

**FlyBird** is a simple single player game where we have to fly a bird while avoiding obstacles.

## Features

1. **Different Difficulties levels** - User can set difficulties level as Easy, Normal or Hard and the game's difficulty would change according to that.
2. **Background Music** - A background music would be playing on while the user plays the game and music can be turned off in settings. 
3. **Score Tracking** - User can track scores and view highest Score
4. **Speed Increase** - The speed of the game gradually increases as the user's score increases.
